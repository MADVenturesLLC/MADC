## Recommendations preview (evidence-backed; final wording in PLAN-MAD-AGENT.md)

**1. omp ADR — recommend Option 3, hybrid: clean MAD core that steals mechanisms, with two omp-compatible seams.** [Likely]
- License permits any option (OMP-08/09 MIT). What decides it is churn + custody fit, not license.
- Churn (OMP-107..116): ~4,700 commits/30 d, ~13,700/90 d, 864 tags, 47 CHANGELOG versions and 11 "Breaking Changes" sections between 2026-08-23 and 2026-09-24 (SDK subpaths moved 18.2.5; header API changed 18.2.3). An SDK consumer breaks weekly; a fork inherits a ~25k-commit Bun/TS + ~80k-line Rust tree with 3,143 open issues.
- Custody mismatch (OMP-88..90, 93..100, 104..106): default approval `yolo`; no OS sandbox; credentials as plaintext TEXT in SQLite, no keychain; ships third-party OAuth client credentials and presents itself as Google's Antigravity client; Anthropic login carries Claude Code fingerprint constants; `apiKey: !command` executes config-supplied commands; extensions are arbitrary TS modules. Every default is the opposite of MAD's (Keychain-only custody MAD-65/66; spend-broker credential gating MAD-87; no silent substitution MAD-96..101; one role/surface/exact model per execution MAD-130).
- Precedent: Evolve Pack v0 already set the MAD norm "mechanism steal, not clone … No OMP code … was read or vendored" (MAD-72..83).
- Seams to keep: (i) MadBridge's picker reads `omp models ls --json` → `{models:[{selector,name,provider,…}]}` (MAD-08..10, OMP-84..86). MAD's `madc models ls --json` emits a superset of that shape so the picker switches source with one env/config change; (ii) read-only importers for omp's JSONL session tree (OMP-68/69) and config, so Layer B can index/resume omp sessions as a third-party agent. No omp code vendored. omp stays a hosted third-party agent in B.
- Runtime: MAD core in TypeScript targeting BOTH Bun (madventures-tui, Bun 1.3.x) and Node 22 (Build Room Gateway) — omp is Bun-only (OMP-19/22), a second reason not to embed it under the Gateway.
- Status: FOUNDER_DECISION_REQUIRED (ADR-01).
